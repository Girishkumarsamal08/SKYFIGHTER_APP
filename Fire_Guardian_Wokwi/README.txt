FIRE GUARDIAN WOKWI PAYLOAD SIMULATION
1. Open Wokwi and create an ESP32 project.
2. Replace diagram.json and sketch.ino with these files.
3. Run the simulation.
4. Change DHT22 temperature/humidity and the MQ2 potentiometer to trigger the two-out-of-three fire decision.
5. This simulates the payload/response logic only. It does NOT simulate real quadcopter flight dynamics.
