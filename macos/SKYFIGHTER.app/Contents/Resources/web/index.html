iPhone & iPad Installation

Zero Developer Fee PWA

Apple restricts direct IPA file installation without a paid developer account. SKYFIGHTER is built as a certified Progressive Web App:

  1. Open this application in Safari on your iPhone or iPad.
  2. Tap the Share button at the bottom of the screen (square with arrow).
  3. Scroll down and tap "Add to Home Screen".
  4. Tap Add. SKYFIGHTER will launch full-screen with offline capabilities!
🤖

Android Phones & Tablets

Direct Install / PWA / APK

No Google Play store account needed:

  1. In Chrome, tap the browser menu (three dots).
  2. Select "Install app" or "Add to Home screen".
  3. The app installs as a native standalone application icon on your launcher.
  4. For native APK builds, enable "Install unknown apps" in Android Settings.
🪟

Windows Desktop & Laptops

Edge / Chrome App

Install directly as a high-performance Windows desktop application:

  1. Open this page in Google Chrome or Microsoft Edge.
  2. Click the Install icon in the right side of the address bar.
  3. Confirm "Install" to add SKYFIGHTER to your Windows Start Menu and Desktop.
  4. Connect to the drone's Wi-Fi network (SKYFIGHTER_GATEWAY).
💻

macOS Desktop & MacBooks

Safari / Chrome Web App / Swift

Distributable without Apple Notarization fees:

  1. In Safari (macOS Sonoma / Sequoia), click File > Add to Dock....
  2. The app will run in its own dedicated sandboxed window like a native Mac application.
  3. Alternatively, build the native Swift app via Xcode with your free Personal Apple ID.

⚠️ Hardware Safety & Legal Notice

SKYFIGHTER ground station software issues safety instructions over Wi-Fi. However, physical motor cutoffs, battery failsafes, and obstacle avoidance depend entirely on onboard firmware stability. Always operate within visual line of sight (VLOS) and comply with local aviation authority regulations.
